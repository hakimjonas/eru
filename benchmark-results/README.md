# Benchmark Results

This directory stores output from local benchmark runs.

## Usage

Benchmark results are generated by running:

```bash
./tools/run-benchmarks.sh
```

Results are stored as timestamped JSON files for analysis and comparison.

## CI Benchmarks

CI benchmark results are uploaded as GitHub Actions artifacts and are not committed to the repository. See `.github/workflows/ci.yml` for CI benchmark configuration.

## Local Benchmarks

Local benchmark results are ignored by git (see `.gitignore`) to prevent repository bloat. If you need to preserve specific benchmark results, consider:

- Storing them in a separate location
- Uploading them as GitHub release artifacts
- Documenting key findings in performance documentation

## Analysis

Use the tools in `tools/` to analyze benchmark results:

- `tools/analyze-benchmarks.sh` - Shell-based analysis
- `tools/analyze-benchmarks.scala` - Scala-based analysis
- `tools/analyze-benchmarks.py` - Python-based analysis
